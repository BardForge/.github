# Сторонние компоненты

Prettier используется для проверки форматирования, лицензия MIT. GitHub Actions `checkout` и `setup-node` используются в CI, лицензия MIT; ссылки закреплены на конкретных коммитах.

Материалы сообщества написаны для BardForge; сторонние аудиозаписи, модели и датасеты здесь не распространяются. Лицензия собственных материалов проекта ещё не выбрана владельцем.
